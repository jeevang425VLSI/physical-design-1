## Overall Learning 

1. Gained hands-on experience with Linux commands and shell environment, including file management, permissions, text processing, navigation, and editing using       commands such as chmod, grep, awk, vi, ls, cd, pwd, mkdir, and rm.
2. Learned TCL scripting and automation for extracting wire length, clock/data wire length, IR drop, levels of logic, and analyzing OpenLane reports.
3. Gained practical knowledge of the OpenLane RTL-to-GDSII flow, including synthesis, floorplanning, placement, CTS, routing, and signoff.
4. Learned to analyze timing, area, power, utilization, routing, clock skew, slack, IR drop, physical-only cells, and library cells at different stages.
5. Performed design verification using TCL scripts, Linux commands, OpenROAD GUI, logs, and reports, verifying that the required physical-design and timing           constraints were successfully implemented.
